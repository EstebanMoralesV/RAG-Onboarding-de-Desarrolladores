# 🚀 CI/CD y DevOps

</div>

La entrega continua es fundamental para mantener la cadencia de innovación sin sacrificar calidad.

## 🔄 Pipeline de Integración Continua

| Etapa | Tecnología | Descripción |
|-------|------------|-------------|
| 🌿 **Control de versiones** | GitHub / GitLab | GitFlow simplificado. |
| 🐳 **Build** | Docker multi-stage | Escaneo de vulnerabilidades con Trivy y Snyk. |
| 🧪 **Pruebas** | Unit + Integration + Contract (Pact) | Validación en cada pull request. |
| 📦 **Artefactos** | Registro privado | Imágenes Docker versionadas y Helm charts. |

## 🚢 Pipeline de Entrega Continua

| Capacidad | Tecnología | Descripción |
|-----------|------------|-------------|
| 🔄 **Despliegue** | ArgoCD | Sincronización automática estado deseado vs. clúster. |
| 🦅 **Estrategias** | Rolling updates / Canary | Canary para cambios de alto riesgo (ej. algoritmo de recomendación). |
| 🎛️ **Feature Flags** | LaunchDarkly | Activar funcionalidades sin despliegue de código. |

## 🏭 Entornos

| Entorno | Propósito | Datos |
|---------|-----------|-------|
| 💻 **Local** | Desarrollo con Docker Compose. | Datos sintéticos. |
| 🧪 **Dev** | Integración continua. | Datos anonimizados. |
| 🏗️ **Staging** | Pre-producción, validación de QA. | Snapshot anonimizado de producción. |
| 🚀 **Production** | Servicio real a usuarios. | Datos reales. |
