# 📖 Glosario de Términos

| Término | Definición |
|---------|------------|
| 🧩 **BFF** | Backend for Frontend. Capa de agregación de APIs específica por tipo de cliente. |
| 🌐 **CDN** | Content Delivery Network. Red de distribución de contenido para baja latencia. |
| 🎬 **DRM** | Digital Rights Management. Tecnología de protección de contenido audiovisual. |
| 📺 **HLS** | HTTP Live Streaming. Protocolo de streaming adaptativo de Apple. |
| 📡 **DASH** | Dynamic Adaptive Streaming over HTTP. Protocolo de streaming adaptativo estándar. |
| 📊 **HPA** | Horizontal Pod Autoscaler. Componente de Kubernetes que escala el número de pods. |
| 🔐 **mTLS** | Mutual TLS. Cifrado bidireccional entre servicios con certificados. |
| ⏱️ **MTTR** | Mean Time To Recovery. Tiempo promedio de recuperación ante un fallo. |
| ⏱️ **MTBF** | Mean Time Between Failures. Tiempo promedio entre fallos. |
| ⏱️ **RPO** | Recovery Point Objective. Máxima pérdida de datos aceptable en un disaster. |
| ⏱️ **RTO** | Recovery Time Objective. Tiempo máximo aceptable de recuperación de servicio. |
| 🎯 **SLO** | Service Level Objective. Objetivo de nivel de servicio. |
| 📊 **SLI** | Service Level Indicator. Indicador medible de nivel de servicio. |
| 🌍 **RUM** | Real User Monitoring. Monitoreo de la experiencia real del usuario. |
| 🛡️ **SIEM** | Security Information and Event Management. Sistema de gestión de eventos de seguridad. |
